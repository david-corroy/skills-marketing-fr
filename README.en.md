# Skills Marketing FR

**47 marketing skills in French for Claude Code** — copywriting, acquisition, conversion, retention, growth. Not a translation: every skill is adapted to the French market (French examples, Brevo/Mailjet, euros incl./excl. VAT) and to French law (GDPR/CNIL, misleading commercial practices, influencer law, SMS rules), with an AI-visibility (GEO) layer built in.

## Installation

**Option 1 — Marketplace plugin (recommended).** In Claude Code:

```
/plugin marketplace add david-corroy/skills-marketing-fr
/plugin install skills-marketing-fr@skills-marketing-fr
```

**Option 2 — Full clone:**

```bash
git clone https://github.com/david-corroy/skills-marketing-fr.git
cp -r skills-marketing-fr/skills/* ~/.claude/skills/
```

**Option 3 — Single skill (sparse checkout):**

```bash
git clone --filter=blob:none --sparse https://github.com/david-corroy/skills-marketing-fr.git
cd skills-marketing-fr
git sparse-checkout set skills/copywriting
cp -r skills/copywriting ~/.claude/skills/
```
