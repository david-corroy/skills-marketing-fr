# Marketing Skills in French for Claude Code

[Français](README.md) · [Español](README.es.md)

Marketing skills for Claude Code written natively in French and built for the French market — not translated from English. They use French company examples, local tooling (Brevo, Mailjet) and bake in GDPR compliance for email capture. Each skill also carries a GEO layer: writing copy that gets cited by ChatGPT, Perplexity and Google AI Overviews. Install by copying the skill folders into `~/.claude/skills/`.

## Available skills

| Skill | What it does |
|-------|--------------|
| [`copywriting`](skills/copywriting/SKILL.md) | Writes and rewrites converting web copy in French, including an "AI-citable writing" (answer-first) section |
| [`lead-magnets`](skills/lead-magnets/SKILL.md) | Plans lead magnets with GDPR-compliant capture, plus a full playbook for the free 7-lesson email course format |

Roadmap: ~8 more skills coming (cold-email, emails, cro, offers, launch, content-strategy, ab-testing, customer-research). Progress: 2/30.
