# Skills de marketing en francés para Claude Code

[Français](README.md) · [English](README.en.md)

Skills de marketing para Claude Code escritos directamente en francés y adaptados al mercado francés — no traducidos del inglés. Usan ejemplos de empresas francesas, herramientas locales (Brevo, Mailjet) e integran el cumplimiento del RGPD para la captura de correos. Cada skill incluye además una capa GEO: redactar para ser citado por ChatGPT, Perplexity y los AI Overviews de Google. Instalación: copia las carpetas de skills en `~/.claude/skills/`.

## Skills disponibles

| Skill | Qué hace |
|-------|----------|
| [`copywriting`](skills/copywriting/SKILL.md) | Escribe y reescribe textos web que convierten, en francés, con una sección « redactar citable para las IA » (answer-first) |
| [`lead-magnets`](skills/lead-magnets/SKILL.md) | Planifica lead magnets con captura conforme al RGPD, más un caso completo: la formación gratuita por correo en 7 lecciones |

Hoja de ruta: ~8 skills más en camino (cold-email, emails, cro, offers, launch, content-strategy, ab-testing, customer-research). Avance: 2/30.
