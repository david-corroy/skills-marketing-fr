# Skills Marketing FR

**47 skills de marketing en francés para Claude Code** — copywriting, adquisición, conversión, retención, growth. No es una traducción: cada skill está adaptado al mercado francés (ejemplos franceses, Brevo/Mailjet, euros con/sin IVA) y al derecho francés (RGPD/CNIL, prácticas comerciales engañosas, ley de influencers, normas SMS), con la capa de visibilidad IA (GEO) integrada.

## Instalación

**Opción 1 — Plugin del marketplace (recomendada).** En Claude Code:

```
/plugin marketplace add david-corroy/skills-marketing-fr
/plugin install skills-marketing-fr@skills-marketing-fr
```

**Opción 2 — Clon completo:**

```bash
git clone https://github.com/david-corroy/skills-marketing-fr.git
cp -r skills-marketing-fr/skills/* ~/.claude/skills/
```

**Opción 3 — Un solo skill (sparse checkout):**

```bash
git clone --filter=blob:none --sparse https://github.com/david-corroy/skills-marketing-fr.git
cd skills-marketing-fr
git sparse-checkout set skills/copywriting
cp -r skills/copywriting ~/.claude/skills/
```
