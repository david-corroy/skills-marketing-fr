# Skills marketing en français pour Claude Code

[English](README.en.md) · [Español](README.es.md)

Des skills marketing pensés pour le marché français, pas traduits de l'anglais : copywriting et génération de leads avec les exemples, les outils (Brevo, Mailjet) et le cadre légal d'ici — RGPD compris. Chaque skill intègre en plus une couche GEO : écrire pour être cité par ChatGPT, Perplexity et les AI Overviews, pas seulement pour Google.

## Installation

```bash
git clone https://github.com/david-corroy/skills-marketing-fr.git
cp -r skills-marketing-fr/skills/* ~/.claude/skills/
```

Ou copiez uniquement les dossiers de skills qui vous intéressent dans `~/.claude/skills/`. Claude Code les détecte automatiquement au prochain lancement.

## Skills disponibles

| Skill | Ce qu'il fait | Apport spécifique |
|-------|---------------|-------------------|
| [`copywriting`](skills/copywriting/SKILL.md) | Écrit et réécrit les textes de pages web qui doivent convertir : accueil, landing, tarifs, fonctionnalités | Choix tutoiement/vouvoiement, chasse aux anglicismes, section « écrire citable pour les IA » (règle answer-first) |
| [`lead-magnets`](skills/lead-magnets/SKILL.md) | Planifie des aimants à leads : format, capture, landing page, diffusion, mesure | Conformité RGPD/CNIL intégrée (consentement, double opt-in), cas complet de la formation e-mail gratuite en 7 leçons |
